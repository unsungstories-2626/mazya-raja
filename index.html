४. आपण प्रत्यक्ष केलेला क्रम

  1. Project व फाइल्स तपासल्या. FL Studio मध्ये mazya raja.flp आधीच उघडा होता. Playlist मध्ये मूळ गाणे, music आणि vocal tracks होते.
  2. Timing तपासले. Project tempo 130 BPM होता. Vocal व music stem प्रत्येकी सुमारे 218.12 सेकंद होते आणि सुरुवात जुळलेली होती. हा project चा tempo आहे; स्वतंत्र beat-detection करून गाण्याचा अचूक नैसर्गिक tempo सिद्ध केलेला नाही.
  3. Vocal चे pitch analysis केले. Python मधील pYIN वापरून प्रत्येक भागातील मुख्य सुरांचा मागोवा घेतला.
  4. Notes स्वच्छ केले. किरकोळ pitch fluctuations, खूप छोटे fragments आणि काही चुकीचे खालच्या सप्तकातील detections दुरुस्त केले.
  5. MIDI तयार केली. अंतिम मूळ transcription मध्ये 625 notes होते. गायकाचे timing ठेवले; सर्व notes जाड beat-grid वर ढकलले नाहीत.
  6. Piano audio तयार केला. संगणकावर आधीपासून असलेल्या FL piano samples ने notes वाजवून स्वतंत्र piano WAV लिहिला.
  7. पहिली एकत्र piano आवृत्ती तयार केली. Piano WAV आणि music stem यांची पातळी संतुलित करून Mazya_Raja_Piano_With_Music.wav बनवला.
  8. नवा project तयार केला. मूळ FLP बदलण्याऐवजी Downloads\Mazya_Raja_Piano\Mazya_Raja_Piano.flp तयार केला. पूर्ण original गाण्याचा track mute केला; vocal च्या जागी piano audio ठेवला.
  9. तुमच्या Piano Roll विनंतीनंतर FL Keys जोडला. Add → ROMpler → FL Keys वापरले.
  10. MIDI notes import केले. FL Keys साठी F7 → Piano Roll च्या menu मधून File → Import MIDI file… → आपली MIDI निवडली.
  11. Pattern ला नाव दिले. वरच्या pattern selector वर right-click → Rename and color… → Piano Melody → Enter. Ctrl+S ने save केले. Saved project मध्ये 625 notes FL Keys channel शी जोडलेले आहेत हे तपासले.
  12. पुढील टप्प्यात तुमच्या project मध्ये Flute व audio_music #2 दिसले. त्या वेळी flute pattern आणि backing track सुरुवातीपासून जुळलेले होते. Flute preset निवडण्याचा आणि मधल्या note edits चा प्रत्येक click मी केलेला किंवा पाहिलेला नाही; म्हणून तो माझ्या प्रत्यक्ष कृतीचा भाग म्हणून दाखवत नाही.
  13. शेवटची merged आवृत्ती export केली. Active Flute pattern + active audio_music #2 यांच्या पूर्ण arrangement मधून WAV आणि MP3 बनवले. Vocal व मूळ पूर्ण गाण्याचे tracks बंद होते.
  14. फाइल्स तपासल्या. Export stereo होता, सुमारे 3:39 मिनिटांचा होता आणि तपासणीत full-scale clipping samples आढळले नाहीत. प्रत्येक स्वर कानाने पडताळल्याचा दावा नाही.

५. Vocal चे MIDI notes कसे झाले?

हा सर्वात महत्त्वाचा मधला टप्पा आहे. MP3 थेट Piano Roll मध्ये टाकून त्याचे notes आपोआप झाले नव्हते. आधी audio-to-MIDI transcription केले, मग ती MIDI FL Studio मध्ये import केली.

  1. वेगळा vocal audio वाचला.
  2. Pitch analysis साठी stereo ची mono प्रत वापरली. अंतिम music track mono केला नाही.
  3. pYIN ने “या क्षणी कोणता मुख्य स्वर आहे?” याचा अंदाज घेतला.
  4. समान स्वर सलग असलेले भाग एका note मध्ये एकत्र केले. सुरुवात, शेवट आणि आवाजाची ताकद नोंदवली.
  5. श्वास, शांतता आणि काही अनिश्चित detections वगळले. लहान अडथळे सांभाळले.
  6. Frequency चे MIDI note number मध्ये रूपांतर केले.
  7. सगळे notes Mazya_Raja_Piano_Melody.mid मध्ये लिहिले.

pYIN ही fundamental frequency शोधणारी पद्धत आहे. त्यानंतरची note grouping व cleanup आपल्यासाठी लिहिलेल्या script ने केली. अधिकृत pYIN माहिती.

मूळ timing जपणे: Vocal मध्ये सुरुवातीला 2 सेकंद शांतता असेल तर ती MIDI मध्येही राहिली पाहिजे. “पहिला note पहिल्या beat वर आणू” म्हणून MIDI डावीकडे सरकवला तर backing सोबत जुळणं बिघडते. वेगळ्या सप्तकातील एखादा note चूक वाटल्यास ऐकून तपासा; सर्व गाण्यांना एकच octave-correction नियम लागू होत नाही.

७. Vocal आणि Music वेगळे करणे — फक्त गरज असल्यास

तुमच्याकडे vocal व instrumental stem आधीच असतील तर हा टप्पा वगळा. आपल्या “माझ्या राजा” कामात हा टप्पा वगळला होता.

नव्या गाण्यासाठी मोफत पर्याय म्हणून Ultimate Vocal Remover — अधिकृत project वापरता येतो. हा पर्यायी workflow आहे; आपल्या गाण्याची separation मी UVR मध्ये केली असा दावा नाही.

  1. अधिकृत project मधून Windows आवृत्ती घ्या व स्थापित करा.
  2. Input म्हणून पूर्ण मूळ गाणे निवडा.
  3. Output folder म्हणून त्या गाण्याचा folder निवडा.
  4. Vocal / Instrumental separation देणारे model निवडा. Model names व download पर्याय आवृत्तीनुसार बदलतात; उपलब्ध vocal-separation model वापरा.
  5. दोन्ही outputs जतन होतील अशी निवड करा. फक्त vocals किंवा फक्त instrumental देणारा पर्याय निवडल्यास दुसरा stem वेगळा तयार करावा लागू शकतो.
  6. Process सुरू करा. Model आधीपासून नसल्यास पहिल्यांदा download लागतो.
  7. दोन्ही फाइल्स ऐका: vocal मध्ये गायक स्पष्ट आहे का, instrumental मध्ये lead vocal शक्य तितका कमी आहे का?
  8. त्या दोन्ही फाइल्सची सुरुवात व duration जपून ठेवा.
खूप संगीत उरलेल्या vocal stem मधून piano notes काढल्यास तबल्याचे, bass चे किंवा इतर वाद्यांचे चुकीचे notes सुद्धा येऊ शकतात. चांगला vocal stem हा पुढील कामाचा पाया आहे. Separation मुळे हलका vocal bleed किंवा artifacts उरू शकतात.

८. Coding शिवाय Audio → MIDI — पर्यायी सोपा मार्ग

आपल्या गाण्यासाठी मी Python/pYIN वापरले. तुम्हाला स्वतः menus वापरून काम करायचे असल्यास Spotify Basic Pitch हा मोफत audio-to-MIDI पर्याय वापरून पाहू शकता. त्याचा परिणाम pYIN सारखाच असेलच असे नाही; notes तपासावे लागतात.

  1. Browser मध्ये अधिकृत Basic Pitch पान उघडा.
  2. Audio निवडण्याच्या जागी फक्त vocal stem द्या. पूर्ण music mix देऊ नका.
  3. Model तयार होण्यासाठी व audio process होण्यासाठी वेळ द्या.
  4. तयार झालेली MIDI download करा.
  5. ती Melody.mid म्हणून गाण्याच्या folder मध्ये ठेवा.
  6. पुढील भागाप्रमाणे FL Studio मध्ये import करा आणि मूळ vocal शी तुलना करा.

Basic Pitch च्या अधिकृत project नुसार एका वेळी एक instrument/source असल्यास परिणाम चांगले मिळतात. त्याचे Python साधन स्थानिक processing साठीही उपलब्ध आहे. अधिकृत माहिती.

Tempo बाबत विशेष लक्ष: आपली मूळ MIDI मी 130 BPM संदर्भात लिहिली, म्हणून FL project सुद्धा 130 BPM ठेवला. दुसऱ्या converter ची MIDI वेगळ्या tempo संदर्भात तयार झालेली असू शकते. फक्त project 130 वर ठेवला म्हणून ती योग्य वेळेत वाजेलच असे नाही. MIDI मधील tempo / import settings तपासा आणि सुरुवातीला, मध्ये व शेवटी vocal सोबत जुळते का ते पाहा. सर्व नवीन गाण्यांना 130 BPM वापरण्याचा नियम नाही.

९. FL Studio मध्ये Piano Roll import — नेमक्या पायऱ्या

१०. Notes पाहणे, ऐकणे आणि दुरुस्त करणे

  1. Piano Roll च्या वरच्या उजव्या बाजूच्या चौकोनी maximize बटणाने editor मोठा करा.
  2. सगळे notes निवडण्यासाठी Ctrl+A.
  3. Piano Roll menu → Zoom → Zoom on selection. आपल्या FL 20 मध्ये Shift+5 होता. त्यामुळे सर्व निवडलेले notes एका दृश्यात येतात.
  4. Individual notes मोठे पाहण्यासाठी Zoom → Quick zoom 2 किंवा Shift+2 वापरला.
  5. फक्त या pattern चे वादन ऐकण्यासाठी वरचा PAT mode निवडा. Space ने play/stop करा.
  6. स्वर चुकला असेल तर तो note वर/खाली हलवा. वेळ चुकली असेल तर डावे/उजवे हलवा. लांबी चुकीची असेल तर note चा उजवा टोक बदलवा.

Timing सुधारताना: प्रथम Snap menu मध्ये लहान grid निवडा किंवा गरजेनुसार snap बंद करा. मोठ्या grid वर पूर्ण melody quantize केल्यास गायकाच्या नैसर्गिक phrasing मध्ये बदल होतो. आपल्या पहिल्या conversion मध्ये कठोर beat quantization केले नव्हते.

FL Studio मध्ये octave label वेगळे दिसू शकते: आपल्या CSV मधील A4 हे FL Studio मध्ये A5 म्हणून दिसले. वेगवेगळ्या software ची octave नावांची convention वेगळी असू शकते. फक्त नाव पाहून संपूर्ण melody एक octave हलवू नका; आवाज आणि MIDI note number तपासा.

  • SONG mode मध्ये सुरुवात, मध्ये आणि शेवट timing तपासलेले.
  • Volume balance आणि clipping तपासलेले.
  • FLP वेगळ्या नावाने save केलेला.
  • Full song, Stereo, Split mixer tracks OFF करून WAV/MP3 export.
  • Export स्वतंत्र player मध्ये ऐकलेला आणि पूर्ण folder backup केलेला.

१८. मूळ scripts आणि तांत्रिक तपशील — इच्छुकांसाठी

तुम्हाला नेमके मी केलेले code पाहता यावे म्हणून या मार्गदर्शकासोबत Process_Scripts folder मध्ये मूळ कामाच्या scripts दिल्या आहेत. या एका गाण्यासाठी लिहिलेल्या scripts आहेत; सर्व गाण्यांसाठी तयार app नाहीत. सामान्य वापरासाठी भाग ६–१४ मधला workflow वापरा.

Scriptप्रत्यक्ष काम
inspect_audio.pyAudio duration, sample rates, project tempo, channels व piano samples तपासले.
convert.pyVocal → pitch → notes → MIDI; piano sample rendering; backing सोबत पहिला piano mix.
finish.pyपहिल्या deliverables ची प्रत तयार केली; नवीन FLP मध्ये piano audio लावला; reference mute केला.
check_instrumental.pyशेवटचे WAV/MP3 duration, stereo आणि audio levels तपासले.

Libraries साठी वापरलेला install command साधारण असा होता; आपल्या संगणकावर Python runtime व packages साठी वेगळे स्थान वापरले होते:

python -m pip install --target "packages" librosa soundfile mido pyflp

यातून आवश्यक dependencies सुद्धा आल्या. PyFLP ला आपल्या Python आवृत्तीत Enum compatibility issue आला; script मध्ये त्यासाठी छोटा compatibility adapter वापरला. FL Studio मध्ये हाताने MIDI import करण्याच्या workflow ला PyFLP ची गरज नाही.

Analysis settings: analysis copy 16 kHz mono; 70–1600 Hz bandpass; pYIN 75–900 Hz; 1024 samples चे frame; 160 samples म्हणजे साधारण 10 ms hop; सुमारे 20-सेकंदांच्या भागांत processing; 5-frame median smoothing. जवळचे सूक्ष्म fragments स्वच्छ करून साधारण 60 ms पेक्षा छोटे final notes वगळले. काही isolated कमी octave detections शेजारच्या melody संदर्भाने दुरुस्त केली. MIDI 960 ticks per beat आणि 130 BPM संदर्भात लिहिली. Piano WAV मात्र 44.1 kHz stereo, 24-bit होता.

दुसऱ्या गाण्यावर मूळ convert.py तशीच चालवू नका. Input filenames, output filenames, tempo आणि piano sample path या script मध्ये ठरावीक आहेत. pitch_analysis.npz cache अस्तित्वात असेल तर जुने analysis वापरले जाते; प्रत्येक नव्या गाण्यासाठी नवीन working/output folder वापरणे आवश्यक आहे. तसेच या गाण्यासाठी केलेली low-octave दुरुस्ती खोल पुरुष आवाजाच्या गाण्यावर चुकीची ठरू शकते. finish.py पुन्हा चालवल्यास आपला आधीचा output project पुन्हा बनवला जाईल; त्यामुळे नंतर केलेले FL edits असलेल्या project वर ती चालवू नका.

हा technical appendix “आपण आतून काय केले?” हे पारदर्शकपणे सांगण्यासाठी आहे. कोणत्याही script मधील paths किंवा settings न समजल्यास मूळ फाइल्सवर प्रयोग करण्याऐवजी नवीन प्रत वापरा.
